# AI Colony Counter App
AI tool to count bacterial colonies on agar plates - 100 Days of AI for Health

**Built by:** Onyekwere Favour Adaeze, Public Health, IMSU
**Challenge:** 100 Days of AI for Health

### Problem
Manual colony counting is slow and error-prone in low-resource labs fighting AMR.

### Solution
AI model that auto-counts colonies from agar plate photos.

### Progress - Day 39
Tested model on 4 agar plates. Early results promising. Needs proper validation.

### Tech Stack
Python, OpenCV, AI model, GitHub
